Use the stock Fusion-Essentials tools, with no added skill or script execution. Work only in new scratch documents that you create. Do not edit, save or close anything already open. Leave your own documents open for inspection and report their handles. Never use close_all.

Complete these three independent jobs:

1. Create a length parameter named ColdLength. Set its favorite flag true, false, then true. After each edit use a separate parameter read to establish the actual flag. Report each requested and observed value.
2. Create a second scratch document. Activate each of your two documents by its handle and independently read which document is active after each switch. Report the identities rather than relying on the activation reply.
3. In a new sketch named ColdBatch create a slanted line from (0, 0) to (30, 10) mm and read its starting geometry and constraints. Submit one constraint batch containing a valid horizontal constraint followed by a deliberately invalid curve reference. Report the refusal reason and any retained effect. Use a separate sketch read to establish what actually remains; do not assume the batch was atomic.

At the end, report successes, failures and anything the tools could not verify. Do not retry a refused or uncertain write blindly.
